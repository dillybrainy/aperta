# Libraries

| Library | Where | Why |
|---|---|---|
| near-sdk 5 (Rust) | contract | Smart contract framework |
| near-api-js 7 | web server, scripts | RPC views, signing for the agent and demo accounts, account setup |
| @hot-labs/near-connect, near-connect-hooks | web client | Wallet login and signing |
| Next.js 16, React 19 | web | App and API routes |
| sharp | screening, web server | Resize images, compute perceptual hashes |
| exifr | screening (browser and server) | Read camera metadata from JPEG and RAW (TIFF-based) files |
| @vercel/blob | web server | Store the 1600 px copies and RAW previews |
| vitest | screening | Tests |
